# 2048 Game

A browser-based implementation of the classic 2048 puzzle game, built with JavaScript. The goal is to combine tiles with the same number to reach the 2048 tile.

## Demo

[Play the Game](https://ratseburzhynskyi.github.io/2048-game/)

## About the Project

This project is a simple, interactive puzzle game created to practice JavaScript fundamentals, game logic, and DOM manipulation.
Players move numbered tiles across a 4×4 grid, combining matching values to increase their score and work toward the 2048 tile.

## Features

- Classic 2048 gameplay
- Interactive 4×4 game board
- Score tracking
- Start and restart game controls
- Tile merging and movement logic
- Win and game-over conditions

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- DOM Manipulation

## How to Play

1. Click **Start** to begin the game.
2. Move the tiles using the available game controls.
3. Combine tiles with the same number to create a tile with a higher value.
4. Keep combining tiles to reach 2048.
5. Restart the game to try again.

## Getting Started

To run the project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/ratseburzhynskyi/2048-game.git
   ```

2. Navigate to the project directory:

   ```bash
   cd 2048-game
   ```

3. Open `index.html` in your browser.
